# Players Dashboard

داشبورد سبک و زیبا برای نمایش بازیکنان سرور از فایل `save-data.txt`

## ویژگی‌ها

- نمایش نام بازیکنان در گرید (حداکثر ۳ ستون)
- کلیک روی هر نام → جزئیات (وضعیت، پول، سلاح‌ها)
- سیستم ورود با نام و رمز موجود در دیتابیس
- بعد از ورود، جزئیات خصوصی (رمز، موقعیت، رنگ و ...) نمایش داده می‌شود
- رفرش خودکار هر ۳۰ ثانیه (فقط وقتی تب باز است)
- کاملاً استاتیک و مناسب GitHub Pages
- حجم بسیار کم

## ساختار فایل `save-data.txt`

```
Player{
approved          ← وضعیت (approved = فعال / pending = غیرفعال)
HOST              ← نام
0000              ← رمز
none              ← فیلد اضافی
cash(25)weapon_m9(0)...   ← موجودی و سلاح‌ها
228, 167, 137     ← رنگ / RGB
0, 285, 0         ← موقعیت آخر
}
```

## نصب روی GitHub Pages

1. ریپازیتوری جدید بسازید (Public)
2. فایل‌های `index.html` و `save-data.txt` را آپلود کنید
3. Settings → Pages → Source را روی `main` / root بگذارید
4. آدرس سایت شما آماده است

## نکات

- برای اضافه کردن بازیکن جدید فقط `save-data.txt` را ویرایش کنید.
- بعد از تغییر فایل، صفحه را رفرش کنید (یا ۳۰ ثانیه صبر کنید).
- ورود با هر حساب بازیکن فقط جزئیات همان حساب را باز می‌کند.
